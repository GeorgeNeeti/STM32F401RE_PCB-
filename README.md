STM32F401RE Evaluation Board

A custom development and evaluation board based on the STM32F401RE microcontroller.

Project Overview

The aim of this project is to design a compact STM32F401RE-based development board with the essential circuits and interfaces required for programming, debugging, and embedded system development.

Current Progress

The following sections have been completed in the schematic:

- STM32F401RE MCU core
- 5V input and 3.3V regulated power supply
- AMS1117-3.3 voltage regulator
- Power filtering and decoupling capacitors
- Reset circuit
- BOOT0 configuration
- 8 MHz external crystal oscillator
- SWD programming and debugging interface
- Power indicator LED
- Electrical Rules Check (ERC) completed successfully

Design Tools

- KiCad
- STM32F401RE microcontroller
- AMS1117-3.3 voltage regulator
